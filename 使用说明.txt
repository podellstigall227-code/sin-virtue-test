《测测你的七宗罪与七美德占比》

────────────────────────
怎么用
────────────────────────
1. 双击 index.html，用浏览器打开即可，不需要联网、不需要后端、不需要安装任何东西。
2. 手机能看：把整个文件夹拷到手机，或丢到任意静态托管（GitHub Pages / Vercel / 公众号菜单等）。
3. 一共 40 题，做完自动出结果，全程约 4 分钟。
4. 结果页顶部那张卡片就是分享卡，长按 / 截图发小红书、朋友圈即可。

────────────────────────
结果怎么读
────────────────────────
· 上面一排是「主罪」和「主美德」：14 个维度里占比最高的那一个。
· 中间那句是你的专属文案：嘴上说着什么，手上做着什么。
· 下面那条是「灵魂天平」：七宗罪合计 vs 七美德合计，两者相加正好 100%。
· 「完整占比」里是 14 项各自的百分比，同样合计 100%（用最大余数法取整，不会出现 99% 或 101%）。
· 占比不是"你有多坏"，而是 14 种倾向之间的相对浓度，仅供娱乐。

────────────────────────
14 个维度
────────────────────────
七宗罪：傲慢 PRIDE、嫉妒 ENVY、暴怒 WRATH、懒惰 SLOTH、贪婪 GREED、暴食 GLUTTONY、色欲 LUST
七美德：谦逊 HUMILITY、仁爱 KINDNESS、忍耐 PATIENCE、勤勉 DILIGENCE、慷慨 CHARITY、节制 TEMPERANCE、贞洁 CHASTITY

────────────────────────
操作小提示
────────────────────────
· 电脑上可按键盘 1 / 2 / 3 / 4 选答案，Backspace 返回上一题。
· 点「重新测试」随时重来；点「复制结果文案」可以把结果复制成一段话，方便粘贴。

────────────────────────
想自己改内容
────────────────────────
所有内容都在 index.html 里，改两处就够：
· 搜 "const QUESTIONS" —— 40 道题，选项格式 ['文案','维度key']。
· 搜 "const TRAITS" —— 14 个维度的名字、英文、描述、文案。
维度 key 一共 14 个：pride / envy / wrath / sloth / greed / gluttony / lust，
以及 humility / kindness / patience / diligence / charity / temperance / chastity。
评分自动归一化：某个维度在你作答里的"命中率"最高，就是你的主罪 / 主美德；占比合计恒为 100%。

────────────────────────
调试用（一般用不到）
────────────────────────
在地址后面加参数可以直接看某一页：
· index.html?preview=quiz      直接看答题页
· index.html?preview=pride     直接看"傲慢 / 谦逊"结果页
· 其余同理：envy / wrath / sloth / greed / gluttony / lust / humility / kindness / patience / diligence / charity / temperance / chastity

────────────────────────
说明
────────────────────────
这是趣味人格测试，不是道德评判，也不是心理诊断。
七宗罪与七美德只是七个"人性切面"，所有文案仅供娱乐。
